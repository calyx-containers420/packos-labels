---
name: manufacturer-setup
description: Connect a manufacturer's own LabelTraxx shop to PackOS, prepare its estimating-engine margins, and rehearse a test label quote through a reviewed ticket.
---

Use the PackOS connector's manufacturer tools for this workflow. Start with packos_open_manufacturer_setup. If the manufacturer tools are absent, report that the connected gateway has not enabled this feature.

1. Confirm the manufacturer's Vault workspace. In the authorized browser, open the returned Connections link, help fill the shop and reserved-range fields, and hand the private credential entry and shop confirmation to the administrator. Never ask for a credential in chat. Use the Customers link to map an existing customer, ship-to and LT product.
2. After the shop is verified, confirm that the owner wants this workspace to be the manufacturer home and call packos_activate_manufacturer_workspace. Existing homes retain their supplier. Use the manufacturer’s own unassigned workspace for a new home. Call packos_manufacturer_state with resume: true. Follow its next step from the current shop and call packos_manufacturer_mappings when you need the selected customer and SKU. Use only this shop's returned identifiers. Read firstSync. Once the owner confirms the shop counts and reserved range, call packos_start_manufacturer_sync with the returned connectionId and generation. Poll manufacturer_state while queued or leased. If the key changed or needs a shop check, return to Connections. On failed or dead show the code, help correct the cause and retry. Continue to pricing only after succeeded. The worker imports equipment, stocks, tooling and materials with the shop's saved credential. Check the current draft. Ask which margin schedule the plant authorizes. Show the change, then use packos_save_manufacturer_pricing_draft. Publishing is a separate owner/admin action on the Pricing page.
3. For a first shop with no mapped customer company, confirm an existing LabelTraxx test customer, ship-to and product, then call packos_set_manufacturer_test_mapping. Use its returned company and SKU for the quote. Otherwise select a mapped reorder SKU. Confirm the actual label dimensions, material, finish, colour count, quantity and ship-by date. Call packos_test_manufacturer_ticket with the chosen connection, customer, schedule and a stable reference. Use the engine's returned price and ticket draft. Missing rates, mappings and exhausted ranges must be resolved in PackOS before retrying.
4. Open the returned review link in the manufacturer's own session. The authorized plant reviewer checks the exact shop, goods, tooling, quantity and ticket, and decides whether to submit. Even a marked TEST ticket can reach a live shop. Hand control to the reviewer for the final decision. On a host without browser control, provide the same link.
5. Call packos_manufacturer_ticket_receipt with the original workspace, customer and reference. Report the actual writer state and external ID. A queued or shadowed run is still unverified. An ambiguous response calls for checking the same run before any retry.

If the plant provides an ERP sample, use the integration-setup skill’s identifier preview before choosing the test customer and SKU. A matched row confirms the saved mapping. The shop’s live product and ticket still require the rehearsal and writer receipt.
